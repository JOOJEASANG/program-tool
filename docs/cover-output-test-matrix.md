# 책표지 출력 검증 매트릭스

기준일: 2026-08-05

## 출력 계산 기준

- 완성 가로(mm) = 뒤표지 재단 폭 + 책등 폭 + 앞표지 재단 폭 + 좌우 도련
- 완성 세로(mm) = 재단 높이 + 상하 도련
- PDF와 가이드 PDF = 300DPI
- PNG 미리보기 = 180DPI
- 픽셀 한 변 = `round(mm × DPI ÷ 25.4)`
- 최종 PDF 페이지 크기 = 계산된 완성 가로·세로(mm)
- PDF 내부 이미지는 페이지 전체에 0,0부터 페이지 폭·높이까지 배치한다.

## 표준 규격 실행 검사

| 사례 | 재단 규격 | 책등 | 도련 | 출력 | 예상 결과 |
|---|---:|---:|---:|---|---|
| A4 일반 교재 | 210×297mm | 8.5mm | 3mm | 300DPI PDF | 약 1,840만 픽셀, 2GB 기기 기준 허용 |
| B5 일반 교재 | 182×257mm | 8.5mm | 3mm | 300DPI PDF | 약 1,390만 픽셀, 2GB 기기 기준 허용 |
| A5 소책자 | 148×210mm | 8.5mm | 3mm | 300DPI PDF | 약 940만 픽셀, 2GB 기기 기준 허용 |
| 최대 사용자 규격 | 300×450mm | 100mm | 10mm | 300DPI PDF | 약 4,720만 픽셀, 4GB 기기에서는 차단·16GB 기기에서는 기존 5,200만 한도 내 허용 |
| 최대 사용자 규격 | 300×450mm | 100mm | 10mm | 180DPI PNG | 약 1,700만 픽셀, 2GB 기기 기준 허용 |
| 과도한 가로 규격 | 900×300mm | 20mm | 3mm | 300DPI PDF | 캔버스 한 변 16,384px 초과로 차단 |

## 기기별 PDF·가이드 PDF 픽셀 한도

| `navigator.deviceMemory` | 최대 픽셀 |
|---:|---:|
| 2GB 이하 | 24,000,000 |
| 4GB 이하 | 34,000,000 |
| 8GB 이하 | 46,000,000 |
| 8GB 초과 또는 정보 없음 | 52,000,000 |

기존 편집기의 절대 한도인 52,000,000픽셀을 초과해서는 안 된다. 예상 작업 메모리는 픽셀당 12바이트로 계산해 렌더 캔버스, 이미지 변환, PNG 인코딩 과정의 임시 메모리를 함께 안내한다.

## 기능 조합 확인 대상

- 자동 책등: 페이지 수·종이 두께·제본 보정값 반영
- 수동 책등: 직접 입력한 책등 폭 반영
- 앞표지 이미지만, 뒤표지 이미지만, 양쪽 이미지
- 이미지 맞춤 `cover`와 `contain`
- 앞·뒤 이미지 회전, 좌우·상하 반전, 밝기·대비·채도
- 앞표지·책등·뒤표지 글자 레이어
- 가이드 없는 완성 PDF
- 재단선·책등선·안전 여백을 포함한 가이드 PDF
- 180DPI PNG 미리보기
- 인쇄 전 점검 오류가 남아 있는 상태의 출력 차단
- jsPDF 최초 CDN 실패 후 출력 시점의 대체 CDN 복구
- 같은 출력 버튼 반복 클릭 시 PDF 라이브러리 중복 로드 방지

## 통과 조건

1. A4·B5·A5 표준 규격이 저메모리 기준에서도 허용된다.
2. 사용자 최대 규격은 기기 메모리 기준에 따라 일관되게 허용 또는 차단된다.
3. PNG는 실제 180DPI 픽셀 수로 판단한다.
4. 차단 시 예상 픽셀 크기와 작업 메모리를 사용자에게 표시한다.
5. PDF 페이지 크기와 래스터 배치가 계산된 밀리미터 규격과 일치한다.
6. PDF 라이브러리 복구는 12초 안에 성공 또는 명확한 실패 상태로 종료한다.
7. 기존 인쇄 전 점검 오류 차단을 우회하지 않는다.
