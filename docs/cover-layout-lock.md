# 책표지 배치 잠금

기준일: 2026-08-06

## 목적

표지 배치를 거의 마친 뒤 미리보기에서 실수로 이미지나 글자를 드래그하거나 마우스 휠로 확대하는 일을 막는다. 잠금은 배치만 보호하며 글자 내용, 색상, 이미지 색감과 출력 기능은 계속 사용할 수 있다.

## 잠기는 기능

- 미리보기 캔버스 드래그·크기 손잡이·더블클릭 초기화
- 이미지 선택 상태에서 마우스 휠 확대·축소
- 가로·세로 위치와 크기 슬라이더
- 선택 가운데 정렬, 선택 초기화, 전체 배치 초기화
- 제목 위치 프리셋
- 책등 상·중·하단 요소의 위치·크기와 가운데 맞춤·초기화
- 입력 요소에 초점이 없는 상태에서 방향키를 이용한 미세 이동

## 계속 사용할 수 있는 기능

- 제목·부제목·기관명·뒤표지·책등 문구 입력
- 글자색과 배경색 변경
- 이미지 밝기·대비·채도·회전·반전
- 규격과 본문 페이지 수 확인
- 인쇄 전 점검과 프로젝트 저장
- PDF·가이드 PDF·PNG 출력

## 이용 방식

- 미리보기 상단의 `배치 잠금` 버튼을 누르면 잠긴다.
- 잠긴 동안 미리보기 오른쪽 위에 `배치 잠금됨` 표시가 나타난다.
- 버튼을 다시 누르면 위치와 크기 조절이 복원된다.
- 잠금 상태는 현재 브라우저에 저장돼 새로고침 후에도 유지된다.
- 잠그기 전부터 비활성화돼 있던 컨트롤은 잠금 해제 후에도 기존 비활성 상태를 유지한다.
