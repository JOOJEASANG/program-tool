# 고급 PDF 편집 업로드·마주보기 변경

- `/pdf-editor-advanced` 파일 불러오기를 배치프로그램과 같은 점선형 클릭/드래그 업로드 영역으로 표시한다.
- 양면 마주보기를 켜면 짝수 출력 페이지에서 좌·우 여백을 반전한다.
- 마주보기 상태는 고급편집 Undo/Redo와 최종 처리 요청에 포함한다.
- 미리보기와 최종 PDF에서 짝수 페이지의 좌·우 머리말/꼬리말 및 좌·우 페이지번호 위치도 같은 방향으로 반전한다.
- 일반 `/pdf-editor` 배치프로그램 사이드바의 `PDF 문서 편집기` 상단 제목만 제거하며 설명과 기존 기능은 유지한다.
