# 책등 글자별 세로쓰기와 회전 방향

## 목적

책표지 제작기의 책등 상단·중앙·하단 및 추가 글자마다 읽는 방향을 독립적으로 지정합니다. 한 책등 안에서도 기관명은 아래에서 위로, 제목은 한 글자씩 세로, 발행처는 위에서 아래로 배치할 수 있습니다.

## 제공 방향

- 아래→위 90°
- 한 글자씩 세로
- 위→아래 90°

책등 탭에서 글자를 선택하면 방향 버튼이 나타납니다. `현재 방향을 모든 책등 글자에 적용` 버튼으로 선택 방향을 한 번에 통일할 수 있습니다.

## 저장과 출력

방향 값은 각 `CoverTextZones` 책등 글자 항목의 `direction` 속성에 저장됩니다. 따라서 다음 경로에서 별도 변환 없이 유지됩니다.

- 브라우저 자동 저장
- 프로젝트 JSON 저장·불러오기
- 최근 작업 복구본
- 미리보기 PNG
- 가이드 PDF
- 300DPI RGB PDF

기존 저장본에 방향 값이 없으면 이전 공통 `책등 방향` 값을 최초 기본값으로 사용합니다.

## 렌더링 안전성

기존 책등 렌더러와 중복 출력되지 않도록 현재 책등 글자 배열과 구형 책등 입력값을 렌더 호출 동안만 비운 뒤 반드시 복원합니다. 앞표지·뒤표지 글자와 이미지, 기존 배치·색상·인쇄 적합성 검사는 그대로 유지합니다.

## 검증

- 세 방향 정규화와 기존 공통 방향 마이그레이션
- 선택 글자와 전체 책등 글자 방향 저장
- 기존 책등 배열·구형 입력값의 렌더 전후 복원
- 세로쓰기 문자 단위 출력과 양방향 90° 회전
- 선택 테두리와 `state.hitBoxes` 유지
- 프로젝트 상태 브리지의 글자 항목 전체 복제 경로 유지
