# PDF home profile entries

Program Studio exposes the PDF editor as two task-oriented home entries while keeping one protected editor shell:

- **PDF 배치용** → `/pdf-editor/` — lightweight layout profile for N-UP, booklet, dividers, margins, and page ordering.
- **PDF 고급편집용** → `/pdf-editor-advanced` — Firebase redirects to `/pdf-editor?profile=advanced`, enabling the advanced page-editing runtime.

The home launcher preserves the print checker and PDF utility entries, for four total home programs and three PDF-category programs.
