# 책표지 300DPI PDF 최종 확인

기준일: 2026-08-06

## 목적

주 출력인 300DPI RGB PDF를 만들기 전에 인쇄 규격과 경고를 한 화면에서 확인한다. 가이드 PDF와 미리보기 PNG는 빠른 검수 기능이므로 기존처럼 즉시 생성한다.

## 표시 항목

- 완성 가로·세로
- 책등 폭
- 전체 펼침 크기
- 재단 여백
- 본문 페이지 수
- 이미지 맞춤 방식
- 실제 저장 파일명
- 앞표지·뒤표지 예상 인쇄 DPI
- 인쇄 전 점검의 오류와 주의사항

## 동작 원칙

1. `300DPI RGB PDF 만들기`를 누르면 기존 출력 전에 최종 확인 화면을 연다.
2. 인쇄 전 자동 점검을 새로 실행해 최신 상태를 사용한다.
3. 오류가 있으면 PDF 생성 버튼을 비활성화한다.
4. 주의사항만 있는 경우 이용자가 내용을 확인한 뒤 출력할 수 있다.
5. `계속 편집`이나 바깥 영역, 닫기 버튼, Esc 키로 작업 화면에 돌아간다.
6. `300DPI PDF 생성`을 누르면 한 번만 확인을 통과시키고 기존 출력·성능·오류 방지 경로를 그대로 실행한다.
7. 가이드 PDF와 PNG에는 확인 단계를 추가하지 않는다.

## 이용 편의

- 작은 화면에서는 화면 하단 시트처럼 열리고 내용이 길면 내부에서 스크롤된다.
- 닫으면 원래 PDF 버튼으로 키보드 초점이 돌아간다.
- 이미지가 없어 배경색만 출력되는 경우도 명확하게 표시한다.
- 오류·주의 항목은 최대 8개까지 먼저 보여주고 왼쪽 인쇄 전 점검 카드에서 전체 내용을 확인할 수 있다.
