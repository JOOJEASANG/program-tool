# PDF 파일별 접기와 빠른 페이지 이동

## 목적

여러 PDF와 수백 페이지가 섞인 작업에서 왼쪽 페이지 목록을 끝없이 스크롤하지 않고 파일 단위로 범위를 파악하고 원하는 페이지로 이동한다.

## 파일 헤더

각 원본 PDF 헤더에 다음 정보를 표시한다.

- 원본 파일명
- 현재 편집 목록에서 차지하는 페이지 범위
- 원본 PDF 페이지 범위
- 현재 남아 있는 페이지 수
- 숨김 페이지 수

파일의 페이지가 편집 순서에서 여러 구간으로 나뉘면 `편집 1–20, 45–60`처럼 표시한다. 구간이 많으면 앞의 두 구간과 추가 구간 수를 표시한다.

## 접기와 펼치기

- 파일 헤더의 화살표로 해당 원본의 페이지만 접거나 펼친다.
- 같은 원본 페이지가 편집 목록의 여러 위치에 나뉘어 있어도 함께 접는다.
- `모두 접기`와 `모두 펼치기`를 제공한다.
- 접기는 표시만 변경하며 페이지 순서, 숨김 상태, 회전, N-up과 원본 매핑은 변경하지 않는다.
- 빠른 이동 대상이 접힌 파일에 있으면 자동으로 펼친다.

## 편집 페이지 이동

편집 목록에서 보이는 순서를 기준으로 1부터 전체 페이지 수까지 입력한다. 빈 페이지와 간지도 편집 페이지 번호에 포함한다.

이동 시:

1. 해당 파일이 접혀 있으면 펼친다.
2. 왼쪽 썸네일을 강조하고 화면 중앙으로 이동한다.
3. 대용량 문서는 지연 미리보기의 해당 출력면을 연다.
4. 일반 문서는 기존 전체 미리보기를 만든 뒤 해당 출력면으로 이동한다.

## 원본 페이지 이동

원본 PDF를 선택하고 해당 PDF의 원본 페이지 번호를 입력한다. 현재 편집에서 삭제된 원본 페이지는 `현재 작업에 없습니다`라고 안내하며 다른 페이지로 잘못 이동하지 않는다.

숨김 처리된 페이지도 위치는 찾되 상태 안내에 `숨김 페이지`를 표시한다.

## 안전성

- 기존 `renderThumbs` 결과가 만들어진 뒤 헤더와 도구만 보강한다.
- 기존 썸네일 요소를 다른 컨테이너로 이동하지 않아 드래그와 우클릭 기준을 유지한다.
- 목록 보강 중에는 MutationObserver를 잠시 중지해 반복 렌더링을 방지한다.
- `parsedPages`, `uploadedFiles`, 최종 PDF 생성과 다운로드 경로는 변경하지 않는다.
