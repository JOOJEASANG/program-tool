# 작업실 사용성 개선 · 2026-10-07

## 사용자 변경사항

- 홈을 작업 목적별 시작 화면으로 개편했습니다. 표지 제작, 인쇄 전 검토, 자동배치, PDF 도구 모음으로 바로 이동합니다.
- ☆ 버튼으로 즐겨찾기를 등록하고, 검색·카테고리와 함께 필터링할 수 있습니다. 최근 방문한 도구는 최대 4개 표시됩니다. 이 정보는 현재 브라우저에 저장되며 작업 파일을 저장하거나 복구하지 않습니다.
- PDF 도구 모음은 실제 통합 작업실인 `/pdf-suite/`로 연결합니다. 전문 검사·보안은 빠른 실행에서 별도로 선택할 수 있습니다.
- 빠른 실행 / 도구 전환 / Ctrl 또는 Cmd+K에서 운영 도구 7개를 검색할 수 있습니다. 이동 전 편집 내용을 저장하세요.
- 인쇄 검토·표지 제작·배치·편집의 설정 패널에 접이식 작업 순서를 제공합니다.
- 스마트 인쇄배치에서 명함 90×50, 엽서 100×148, A5 안내장 148×210mm 재단 크기를 빠르게 입력합니다. 용지·양면·여백 설정이나 원본 배율은 변경하지 않습니다.
- 검색 결과 수를 보조기기에 안내하고, 빠른 실행의 키보드 포커스 순환·닫은 뒤 원위치 복귀를 추가했습니다.

## 검증

- 변경 전 / 변경 후 백엔드·소스 회귀검사: 각각 1,070개 통과.
- JavaScript·inline script·Python 구문, 정적 참조, 런타임 자산, 경로 예산, 모듈 경계, 버전 동기화 통과.
- CI와 동일하게 `python scripts/inject_boot_guard.py` 실행 후 배포 메타데이터·Hosting 검증 통과. 빌드로 생성된 HTML 수정은 소스 변경에 포함하지 않았습니다.
- DOM 환경에서 즐겨찾기 저장, 검색·카테고리 결합, 빈 결과 복구, PDF 도구 라우팅, 빠른 실행 검색·포커스 복귀, 저장소 오류 처리, 재단 프리셋·최근 방문 기록을 확인했습니다.
- 로컬 Chromium 실행은 환경의 socket 권한 제한으로 차단되었습니다. 시각적 배치, 실제 인증 상태, 보호된 도구의 파일 업로드·출력까지 브라우저에서 검증했다는 의미는 아닙니다.
- 재현 가능한 브라우저 회귀검사: `npm ci && node scripts/run_workspace_smoke.mjs`. Chrome/Chromium이 필요하며 `CHROMIUM_PATH`로 실행파일을 지정할 수 있습니다. 테스트는 외부 서비스와 보호된 처리 엔진을 모킹하며 실제 PDF 출력은 실행하지 않습니다.

기존 인증·승인·API 권한 정책과 PDF 렌더링 엔진은 변경하지 않았습니다. 배포 전에 실제 회원 세션으로 각 도구 진입과 파일 업로드·저장을 확인하세요.
