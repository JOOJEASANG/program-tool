# PDF 편집기 활성 런타임 기준

기준일: 2026-07-31

## 운영 원칙

PDF 편집기는 2026년 7월 20일 정상 동작본을 기준으로 복원한 뒤, 필요한 기능만 기존 활성 모듈에 직접 통합한다. 과거처럼 여러 보조 파일이 같은 전역 함수를 반복 감싸거나 주기적으로 감시하는 구조는 다시 활성화하지 않는다.

## 활성 모듈 8개

`js/pdf-editor/loader.js`가 다음 파일만 순서대로 불러온다.

1. `font-render-fix.js`
2. `upload-fix.js`
3. `live-preview.js`
4. `layout-export.js`
5. `page-count-hint.js`
6. `nup-helper.js`
7. `preview-row-default.js`
8. `divider-helper.js`

PDF 편집기 경로에서는 `js/sw-register.js`가 `crop-marks.js`를 한 번 추가로 불러온다. 이 파일은 재단선·도련 작업영역, 사이드바 고정, 개별 여백 마주보기, 문서 오버레이 위치 보정을 함께 담당한다.

## 현재 통합 완료 기능

- 대용량 업로드와 실패 롤백
- 미리보기 요청 직렬화와 제한 미리보기
- 썸네일 클릭 이동과 우클릭 숨김
- 다중 선택, 일괄 회전·숨김·표시·복제·이동·삭제
- 실행 취소·다시 실행
- 파일별·페이지별 N-up과 소책자 안내
- 출력면별 원본 페이지 표시
- 고급 간지 편집
- 좌·우·상·하 개별 여백과 양면 마주보기
- 머리말·꼬리말·페이지번호의 비대칭 좌우 여백 반영
- 페이지번호 공간 자동 확보의 미리보기·최종 PDF 동기화
- 재단선과 0~15mm 도련 작업영역의 미리보기·저장·세션 복원

도련 단계는 원본 그림이나 배경을 자동으로 확대하지 않는다. 원본 PDF에 도련 이미지가 없으면 완성 규격 밖의 확보 영역은 흰색으로 남는다.

## 향후 선별 통합 대상

다음 파일은 저장소에 남아 있으나 현재 운영 로더에서는 불러오지 않는다. 파일 전체를 그대로 활성화하지 않고 필요한 기능만 현재 8개 구조에 맞춰 선별 통합한다.

- `page-number-auto-reserve.js`
- `page-number-auto-reserve-layout-v2.js`
- `page-number-preview-parity.js`
- `operation-progress-summary.js`

페이지번호 관련 과거 파일은 현재 `layout-export.js`에 필요한 기능이 이미 통합돼 있으므로 비활성 유지한다. 다음 우선순위는 저장 전 설정 확인·진행률·취소, 실패 후 상태 복구다.

## 비활성 유지 대상

다음 유형의 과거 보조 래퍼는 현재 안정 구조와 충돌 가능성이 있어 활성화하지 않는다.

- 별도 미리보기 컨트롤러와 중복 도킹 보정
- 주기적 무결성 감시
- 전역 렌더 함수의 반복 래핑
- `setInterval` 기반 DOM 보정
- 현재 모듈에 이미 통합된 기능의 중복 구현
