# PC 전용 도구 모바일 안내

## 적용 대상

- PDF 편집기
- 책표지 제작기

기존 편집·저장·출력 기능은 변경하지 않습니다. 모바일 환경에서 접속했을 때만 PC 사용을 권장하는 안내창을 표시합니다.

## 안내 내용

- 정밀 편집과 고해상도 출력은 PC에 최적화됨
- 모바일 화면에서는 편집 도구 사용이 불편할 수 있음
- 터치 중 요소가 의도하지 않게 이동하거나 크기가 바뀔 수 있음
- 안정적인 작업을 위해 PC 사용 권장

## 이용자 선택

- `그래도 계속 보기`: 안내를 닫고 현재 프로그램을 그대로 이용
- `도구 목록으로`: 메인 도구 목록으로 이동
- `오늘 하루 다시 보지 않기`: 같은 브라우저에서 해당 날짜 동안 안내 숨김
- Esc 키: 안내를 닫고 계속 이용

## 기기 판정

다음 중 하나를 만족하면 모바일 환경으로 판단합니다.

- 브라우저의 `userAgentData.mobile` 값이 참
- 모바일 사용자 에이전트
- 900px 이하 화면과 거친 포인터 입력이 동시에 감지됨

PC에서 브라우저 창만 작게 줄인 경우에는 일반적으로 안내를 표시하지 않습니다.

## 안전 범위

- PDF 편집기 상태와 페이지 배열에 접근하지 않음
- 책표지 레이어와 캔버스 렌더러에 접근하지 않음
- 파일 업로드·저장·출력을 차단하지 않음
- 자동 이동이나 강제 리다이렉트를 사용하지 않음
- 두 프로그램 경로에서 공통 모듈을 한 번만 로드
