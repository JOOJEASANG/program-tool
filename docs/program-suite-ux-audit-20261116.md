# Program Studio 전체 프로그램 UX/UI 점검 및 개선 (2026-11-16)

## 대상
운영 중인 6개 프로그램과 메인 런처, PDF 검사/보안 전문 경로를 대상으로 가독성과 조작성을 개선했습니다.

| 경로 | 개선 대상 | 주요 검증 |
| --- | --- | --- |
| / | 카테고리 메뉴, 모바일 햄버거, 즐겨찾기 카드 | 메뉴 44px, Esc 종료 및 초점 복귀 |
| /print-checker/ | 사양·제품 선택, 업로드, 검토 결과 | 입력/선택 버튼 가독성, 모바일 메뉴 |
| /smart-print-layout/ | 인쇄 설정, 입력값, 상단 세션 버튼 | 39px 세션 버튼, 입력 가독성 |
| /pdf-editor/ | 인쇄 설정, 페이지 목록, 미리보기 | 기존 접기/펼치기 개선 유지, 툴바 정돈 |
| /pdf-editor-advanced/ | 페이지 편집·여백·정밀 입력 | 버튼/숫자 입력 크기, 선택 상태 |
| /ai-design-maker/ | 3개 단계 메뉴, 디자인·문구 입력 | 명시적인 펼치기/접기, native details |
| /pdf-suite/ | 도구 선택 및 로컬 파일 처리 | 홈 버튼, 도구 카드, 업로드 안내 |
| /pdf-preflight/ | 업로드, 검사/보안 작업, 결과 모달 | 작업 카드, 모달 닫기, 모바일 1열 |

## 작업 방식과 안전 경계
- css/program-suite-ux-20261116.css: 각 HTML의 data-suite-screen 값을 사용하여 스타일을 적용합니다.
- 기존 PDF/인쇄 파일 처리, 원본 벡터 보존, 미리보기 캔버스, 인쇄 PDF 생성, 소책자, 저장 로직은 수정하지 않습니다.
- 홈 모바일 사이드바에 상태별 접근성 이름, Esc 종료 및 초점 복귀를 추가했습니다.
- tests/browser/program-suite-unified-ux-smoke.html: 8개 화면의 터치 대상, AI 메뉴 상태, 모바일 그리드 브라우저 검사.
- backend/tests/test_program_suite_unified_ux_20261116.py: 모든 진입점 스타일 연결 및 기능 비간섭 계약 검사.
- 배포 전 GitHub Actions 전체 Python/JS, PDF 브라우저 회귀, 호스팅·보안 검사를 다시 수행합니다.

## 운영 검수 한계
자동 검사는 코드·브라우저 기능과 화면 크기별 표시를 검사하지만 사용자별 원본 인쇄물, 프린터 급지·양면 설정 및 모든 실제 기기 상태를 동일하게 재현하지는 못합니다.
