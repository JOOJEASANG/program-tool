# 표지 글자 미리보기 직접 조절과 자석 자동정렬

## 이용 흐름

표지 미리보기에서 앞표지·책등·뒤표지 글자를 클릭하면 선택 테두리와 조절 도구가 표시됩니다.

- 글자 본문을 드래그해 이동
- 네 모서리 손잡이를 드래그해 크기 조절
- `−`, `＋` 버튼으로 5% 단위 크기 조절
- 왼쪽·가운데·오른쪽 안전 여백 정렬
- 위·가운데·아래 안전 여백 정렬
- 방향키로 0.5% 미세 이동
- Shift+방향키로 2% 이동
- `자석 ON/OFF`로 자동정렬 전환

## 자석 자동정렬

드래그 중 선택 글자의 왼쪽·중앙·오른쪽 또는 위·중앙·아래가 다음 기준에 가까워지면 자동으로 붙습니다.

- 현재 면의 안전 여백
- 현재 면의 가로·세로 중앙
- 같은 앞표지·책등·뒤표지에 있는 다른 글자의 변과 중앙

붙는 순간 청록색 정렬선과 기준 이름을 표시합니다. 자석 설정은 브라우저에 저장됩니다.

## 책등 글자

책등 글자도 미리보기에서 가로·세로 이동과 크기 조절이 가능합니다. 기존 글자별 방향 설정인 아래→위 90°, 한 글자씩 세로, 위→아래 90°를 그대로 사용하며 이동 좌표가 PNG·가이드 PDF·300DPI PDF에 동일하게 반영됩니다.

## 저장과 복구

위치와 크기는 기존 `state.layout`에 저장되고 글자 데이터는 `CoverTextZones` 저장 경로를 사용합니다. 따라서 다음 기능과 호환됩니다.

- 브라우저 자동저장
- 프로젝트 저장·불러오기
- 최근 작업 복구본
- 배치 잠금
- 인쇄 전 점검
- PNG·가이드 PDF·300DPI PDF 출력

## 안전성

- 글자가 아닌 미리보기 영역은 기존 이미지 선택·이동 동작에 전달합니다.
- 배치 잠금 상태에서는 선택 테두리, 손잡이와 정렬 도구를 숨기고 이동·크기 변경을 차단합니다.
- 기존 책등 렌더러의 중복 출력을 막기 위해 렌더 호출 동안 책등 배열만 임시로 비우고 `finally`에서 복원합니다.
- 최종 렌더 파이프라인 소유자가 설치되기 직전에 현재 렌더러를 한 번만 감쌉니다.
