# 책표지 이미지 인쇄 품질 진단

기준일: 2026-08-06

## 목적

화면에서 정상적으로 보이는 이미지라도 표지 크기에 맞춰 확대하면 실제 인쇄 해상도가 낮아질 수 있다. 책표지 제작 프로그램은 앞표지와 뒤표지의 원본 픽셀, 작업 규격, 재단 여백, 이미지 맞춤 방식과 현재 확대율을 이용해 예상 인쇄 DPI를 표시한다.

## 계산 기준

- 이미지 영역 가로: 완성 가로 + 바깥쪽 재단 여백
- 이미지 영역 세로: 완성 세로 + 위아래 재단 여백
- 자동 채우기: 이미지가 영역을 완전히 덮는 배율 사용
- 전체 보이기: 이미지 전체가 영역 안에 들어오는 배율 사용
- 사용자가 이미지를 확대하면 예상 DPI는 확대 배율에 반비례해 낮아진다.

예상 DPI는 `25.4 ÷ 이미지 한 픽셀이 차지하는 실제 mm`로 계산한다.

## 표시 단계

| 예상 DPI | 표시 | 의미 |
|---:|---|---|
| 300 이상 | 최적 | 고품질 인쇄에 적합 |
| 250~299 | 양호 | 일반 인쇄에 적합 |
| 180~249 | 주의 | 가까이 보면 흐릴 수 있음 |
| 120~179 | 낮음 | 인쇄 시 흐림 가능성이 큼 |
| 120 미만 | 위험 | 더 큰 원본 이미지 권장 |

## 추가 안내

- 자동 채우기에서는 영역 밖으로 잘리는 이미지 비율을 함께 표시한다.
- 전체 보이기에서는 비율 차이 때문에 가장자리에 배경색이 보이는 경우를 표시한다.
- 이미지가 없으면 오류가 아니라 배경색만 출력된다고 표시한다.
- 이미지 교체·복사·삭제, 관리자 이미지 템플릿 적용, 규격·맞춤·확대율 변경 후 자동으로 다시 계산한다.
- 품질 진단은 정보와 경고를 제공하지만, 이용자가 의도적으로 저해상도 이미지를 출력하는 것을 강제로 차단하지 않는다.
