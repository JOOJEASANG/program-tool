# 책표지 최근 작업 복구본

기준일: 2026-08-06

## 목적

브라우저 종료, 새로고침, 잘못된 초기화나 이전 상태 복원이 필요할 때 최근 작업 시점으로 돌아갈 수 있게 한다. 기존 단일 자동저장과 달리 규격·문구·배치뿐 아니라 글자 레이어, 이미지 효과와 원본 앞·뒤표지 이미지도 함께 보관한다.

## 저장 구조

- 브라우저 IndexedDB의 `programToolCoverRecovery` 데이터베이스 사용
- 최신 자동 저장 1개를 `working` 슬롯에 유지
- 자동 또는 직접 저장한 복구 지점은 최근 5개 유지
- 변경 후 1.6초 동안 추가 입력이 없으면 최신 상태 저장
- 자동 복구 지점은 최소 3분 간격으로 생성
- `현재 상태를 복구 지점으로 저장`을 누르면 즉시 별도 지점 생성

## 이미지 보관

- 사용자가 올린 JPG·PNG·WEBP 원본은 Data URL 상태로 보관
- 관리자 이미지 템플릿은 원본 HTTPS 주소를 보관
- 동일한 앞·뒤표지 이미지는 지문을 계산해 한 번만 저장
- 어떤 복구본에서도 사용하지 않는 이미지 사본은 자동 삭제
- 브라우저 저장공간이 부족하면 현재 작업은 유지하고 오류를 안내

## 복구 범위

- 완성 규격·재단 여백·안전 여백
- 본문 페이지 수·종이 두께·책등 보정과 직접 책등 폭
- 앞·뒤표지·책등 색상과 기본 글자 설정
- 앞표지·뒤표지·책등의 문구
- 모든 이미지와 글자 요소의 위치·크기
- 글자 레이어 전체
- 이미지 회전·반전·밝기·대비·채도
- 가이드 표시 상태
- 앞·뒤표지 원본 이미지와 표시 이름

## 복원 원칙

1. 프로그램이 임의로 이전 작업을 자동 복원하지 않는다.
2. 이용자가 `복구본`을 열고 날짜와 제목을 확인한 뒤 직접 선택한다.
3. 선택한 상태를 적용하기 전에 현재 화면 상태를 별도 직접 저장 지점으로 남긴다.
4. 일부 원본 이미지를 불러오지 못해도 나머지 규격·문구·배치 복원은 유지하고 누락 사실을 알린다.
5. 복원 후 입력 컨트롤과 미리보기, 책등 계산을 모두 다시 동기화한다.

## 관리

- 각 항목에는 제목, 저장 종류, 저장 시각과 원본 이미지 포함 개수를 표시한다.
- 개별 복구본 삭제와 전체 복구본·이미지 사본 삭제를 지원한다.
- 전체 삭제를 실행해도 현재 화면에서 작업 중인 표지는 사라지지 않는다.
- 최근 작업 복구 데이터는 현재 브라우저에만 저장되며 다른 기기나 브라우저와 동기화되지 않는다.
