# 관리자 서비스 운영 관리

## 관리자 페이지 구조

관리자 페이지는 다음 운영 항목을 중심으로 사용합니다.

- 대시보드
- 회원·구독
- 사업자·정책
- 서비스 관리

`서비스 관리`는 회원에게 제공되는 프로그램을 서비스 단위로 확장하기 위한 영역입니다.

현재 서비스 카드:

- 책표지 제작
- PDF 편집
- PDF 검사

PDF 편집과 PDF 검사는 운영 화면을 바로 열 수 있고, 추후 서비스별 설정이 필요할 때 같은 서비스 관리 구조 안에 기능을 추가합니다.

## 책표지 제공 이미지

책표지 제작 서비스에는 `제공 이미지 라이브러리`를 둡니다.

관리자는 이미지 한 장씩 다음 정보와 함께 등록합니다.

- 이미지 이름
- 분류
- 회원 공개 / 관리자 전용
- JPG·PNG·WEBP 원본 이미지 (15MB 이하)

앞표지와 뒤표지를 한 세트로 강제하지 않습니다.

사용자는 책표지 제작기에서 공개된 이미지를 보고 각 이미지의:

- `앞표지에 적용`
- `뒤표지에 적용`

중 하나를 선택합니다.

## 저장 구조

기존 Firebase 보안 규칙을 재사용하기 위해 Firestore `cover_templates`와 Storage `cover_templates/{id}/`를 그대로 사용합니다.

제공 이미지 문서는 다음 구분값을 가집니다.

- `kind: library-image`
- `name`
- `category`
- `isPublic`
- `imageUrl`
- `imagePath`

기존 앞·뒤 이미지 세트형 문서와 구분되므로 기존 데이터는 삭제하거나 변환하지 않습니다.

## 권한

- 등록·수정·삭제: 관리자만 가능
- 관리자 전용 이미지 읽기: 관리자만 가능
- 회원 공개 이미지 읽기: 승인 회원과 관리자
- 일반 사용자의 관리자 CRUD UI는 책표지 제작기에서 숨김
