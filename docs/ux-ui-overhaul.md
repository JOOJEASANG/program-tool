# Program Studio UX/UI 전면 개편

## 목표

기능 처리 로직은 보존하면서 사용자가 처음 진입한 순간부터 결과 파일을 저장할 때까지 화면 구조, 정보 위계, 조작 밀도, 모바일 대응, 접근성을 하나의 제품 경험으로 통일한다.

## 전체 진단

### 1. 화면마다 디자인 규칙이 다름

홈, 로그인, 관리자, PDF 편집기, PDF 검사, 디자인 편집기, 문서 편집기, 이미지 편집기가 각각 별도 색상·간격·버튼 크기·모서리·그림자 규칙을 사용한다. 기능은 연결되어 있지만 사용자는 서로 다른 프로그램을 이동하는 느낌을 받는다.

### 2. 편집기 조작부의 글자와 터치 영역이 작음

특히 디자인 편집기에는 8~10px 수준의 설명·필드·상태 텍스트가 많아 장시간 작업 시 읽기 어렵다. 문서/이미지 편집기도 기능이 늘수록 왼쪽 패널 밀도가 높아지는 구조다.

### 3. 작업영역 확보 방법이 없음

PDF, 디자인, 문서, 이미지 편집기는 왼쪽 패널이 항상 작업영역을 차지한다. 미리보기와 캔버스가 중요한 프로그램인데도 필요할 때 편집 공간을 넓히는 공통 동작이 없다.

### 4. 프로그램 간 이동 비용이 큼

사용자가 다른 도구로 이동하려면 홈으로 돌아간 뒤 카테고리를 다시 찾는 흐름이 기본이다. 여러 도구를 연속으로 사용하는 실제 인쇄 업무 흐름과 맞지 않는다.

### 5. 홈 정보 구조가 소개 중심임

현재 홈은 카테고리 소개와 프로그램 카드가 중심이다. 기능이 더 늘어나면 원하는 도구를 찾는 시간이 길어질 수 있다. 빠른 실행 또는 전역 검색 계층이 필요하다.

### 6. 유지보수 관점에서 화면 스타일이 분산됨

여러 HTML 파일과 개별 CSS에 스타일 규칙이 중복되어 있다. `pdf-editor/index.html`처럼 큰 단일 파일도 있어 기능 추가 시 시각적 일관성을 유지하기 어렵다.

## Phase 1 — 공통 UX 기반

이번 단계에서 적용한다.

- 공통 색상, 여백, 모서리, 그림자, 포커스 규칙 추가
- 홈 카드와 내비게이션 가독성 개선
- 로그인 화면을 데스크톱 2단 레이아웃으로 개선
- 관리자 화면 카드·메트릭·입력창 밀도 정리
- PDF 편집기 패널, 입력창, 업로드, 주요 버튼 크기 개선
- 디자인 편집기의 8~10px 중심 조작 텍스트를 읽기 쉬운 크기로 상향
- 문서/이미지 편집기 패널과 작업영역 시각 계층 통일
- PDF/디자인/문서/이미지 편집기에 `작업 패널` 접기/펼치기 추가
- 패널 상태를 브라우저에 저장해 다음 방문 때 복원
- `Ctrl/Cmd + K` 전역 빠른 실행 추가
- 키보드 포커스 표시와 `prefers-reduced-motion` 대응 추가

## Phase 2 — PDF 편집기 작업 흐름 재설계

예정 항목:

1. 왼쪽 기능을 `파일 → 배치 → 꾸미기 → 출력` 순서로 재편
2. 기본 기능과 고급 기능 분리
3. 현재 설정을 한눈에 보는 요약 카드 추가
4. 최종 출력 버튼을 항상 찾을 수 있는 위치로 고정
5. 소책자/N-up 선택 시 관련 없는 설정 자동 접기
6. 미리보기 상단에 확대/축소/페이지 이동을 일관된 툴바로 통합
7. 모바일에서는 왼쪽 패널을 드로어 형태로 전환

## Phase 3 — 디자인 편집기 재설계

예정 항목:

1. `추가`, `선택 요소`, `레이어`, `인쇄 검사`를 명확한 탭 구조로 정리
2. 자주 쓰는 항목은 기본 영역, 정밀 수치는 고급 영역으로 분리
3. 선택한 객체 바로 위/옆에 문맥형 퀵툴바 제공
4. 레이어 패널 검색, 잠금, 숨김 상태를 더 명확하게 표시
5. 저장/출력 상태를 상단 고정 상태 영역으로 통합
6. 출력 전 오류를 오른쪽 검사 패널에서 직접 해결할 수 있게 연결

## Phase 4 — PDF 검사 / 문서 / 이미지 편집기

- PDF 검사 결과를 `문제 있음 / 확인 필요 / 정상` 우선순위로 재배치
- 자동 수정 가능한 항목은 결과에서 바로 실행
- 문서 편집기의 서식 도구를 그룹화하고 모바일 툴바 개선
- 이미지 편집기의 작업 순서를 `불러오기 → 보정/자르기 → 크기 → 출력`으로 정리
- 공통 업로드/다운로드/진행 상태 컴포넌트로 통일

## Phase 5 — 홈과 관리자 완성

- 최근 사용 프로그램과 최근 작업 진입점
- 즐겨찾기 프로그램
- 전체 프로그램 검색/필터
- 관리자 회원 목록을 표/카드 전환 가능하게 개선
- 대량 승인·상태 변경의 안전한 일괄 작업 UX
- 모바일 관리자 내비게이션 단순화

## 완료 기준

- 주요 동작의 최소 클릭 수 감소
- 데스크톱과 모바일에서 핵심 기능을 숨김 없이 접근 가능
- 10px 미만의 필수 조작 텍스트 제거
- 키보드만으로 주요 화면 탐색 가능
- 패널 접기 후 캔버스/미리보기 영역이 즉시 확장
- 모든 화면에서 동일한 버튼·입력·상태 표현 규칙 사용
- 기존 PDF/디자인 출력 기능의 회귀 테스트 유지
