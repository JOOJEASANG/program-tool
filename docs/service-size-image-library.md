# 규격별 서비스 이미지 라이브러리

관리자 `서비스 관리`에서 PDF 편집기의 간지와 책표지 제작에 제공할 이미지를 한 곳에서 관리한다.

## 관리 정보

- 사용처: `cover`, `pdf-divider`, 또는 둘 다
- 규격: A5, B5 ISO, B5 JIS, A4, A3, B4, A3 이상 펼침, 직접 입력
- 실제 가로/세로(mm)
- 책표지 방식: 앞/뒤 개별 또는 펼침
- 회원 공개 / 관리자 전용
- 이미지 이름과 분류

데이터는 기존 관리자 보안 규칙을 재사용하기 위해 Firestore `cover_templates`와 Storage `cover_templates/{id}/`를 사용하며 `kind: service-image-v2`로 구분한다.

## 책표지 제작

개별 이미지는 현재 완성 규격과 크기가 맞을 때 표시되며 앞표지와 뒤표지에 각각 적용할 수 있다. 펼침 이미지는 앞표지와 뒤표지를 따로 자르지 않고 전체 작업 폭에 한 번 그려서 뒤표지 → 책등 → 앞표지가 끊김 없이 이어진다. 앞표지나 뒤표지 개별 이미지를 추가하면 해당 면만 펼침 이미지 위에 덮어쓴다.

로컬 파일도 `펼침 이미지 직접 넣기`로 같은 방식으로 사용할 수 있다. A3 이상 또는 충분한 가로 해상도의 이미지를 권장한다.

## PDF 편집 간지

간지 편집창에는 현재 출력 용지의 가로/세로와 약 3mm 이내로 맞는 공개 이미지가 표시된다. 선택한 이미지 ID/Storage 경로는 `dividerContent`에 저장된다.

최종 PDF 생성 서버는 클라이언트가 제출한 경로를 그대로 신뢰하지 않는다. Firestore에서 다음을 다시 확인한 경우에만 Storage 원본을 읽는다.

- `kind == service-image-v2`
- `isPublic == true`
- `targets`에 `pdf-divider` 포함
- 문서의 `imagePath`와 요청 경로가 정확히 일치
- Storage 경로의 문서 ID와 Firestore 문서 ID가 일치
- 원본 크기 15MB 이하

## 제외 서비스

PDF 검사 서비스에는 제공 이미지 기능을 연결하지 않는다.
