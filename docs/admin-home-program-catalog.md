# 관리자 홈 카테고리·프로그램 관리

관리자는 `/admin`의 `카테고리·프로그램` 메뉴에서 홈 상단 카테고리와 프로그램 카드를 관리합니다.

## 카테고리

- 카테고리명 자유 수정
- 카테고리 추가·삭제
- 홈 공개/숨김
- 드래그 또는 ↑ ↓ 버튼으로 순서 변경
- 강조 색상, 프로그램 영역 제목, 상단 소개 문구 수정

## 프로그램

- 프로그램명 자유 수정
- 프로그램 추가·삭제
- 프로그램 URL, 설명, 아이콘, 태그 수정
- 사용 가능/준비 중 전환
- 홈 공개/숨김
- 드래그 또는 ↑ ↓ 버튼으로 같은 카테고리 안에서 순서 변경
- 프로그램을 다른 카테고리 위로 드래그하거나 `소속 카테고리`를 선택해 이동

## 데이터와 안전성

- Firestore `settings/public_program_catalog` 문서에 한 번에 저장합니다.
- 공개 홈은 이 문서를 읽을 수 있지만 쓰기는 관리자만 가능합니다.
- 문서가 없거나 읽기에 실패하면 기존 `index.html`의 고정 카테고리와 프로그램 목록을 그대로 사용합니다.
- 관리자 입력 문자열은 홈 렌더링 전에 정규화하며 프로그램 카드 HTML에 들어가는 값은 이스케이프합니다.
- 기존 회원별 `settings/programs`, `user_permissions`, 프로그램 접근 권한은 변경하지 않습니다.

## 배포 흐름

관리자에서 `저장하고 홈에 반영`을 누른 뒤 홈을 새로 열면 저장된 카테고리명, 프로그램명, 순서, 위치와 공개 상태가 적용됩니다.
