# 책표지 편집 실행 취소·다시 실행

책표지 제작 중 발생하는 실수를 즉시 되돌릴 수 있도록 미리보기 상단에 **취소**와 **다시** 버튼을 제공합니다.

## 이용 방법

- `취소` 또는 `Ctrl/Cmd + Z`: 최근 편집을 되돌립니다.
- `다시` 또는 `Ctrl/Cmd + Y`: 되돌린 편집을 다시 적용합니다.
- macOS에서는 `Cmd + Shift + Z`도 다시 실행으로 동작합니다.
- 글자 입력, 규격 변경, 색상 변경, 이미지 변경, 미리보기 이동·크기 조절을 기록합니다.
- 방향키 이동이나 슬라이더처럼 연속된 조작은 여러 단계가 아니라 한 번의 편집으로 묶습니다.

## 안전 설계

- 최근 40단계만 메모리에 보관해 장시간 편집 시에도 무한히 늘어나지 않습니다.
- 원본 이미지의 데이터 URL을 단계마다 복제하지 않고 같은 이미지 객체를 참조합니다.
- 규격, 입력값, 중복 값을 가진 선택 항목의 정확한 선택 위치, 전체 배치, 표지 글자 레이어, 이미지 효과를 함께 저장합니다.
- 복원 후 다시 캡처한 상태가 목표 상태와 다르면 복원을 실패 처리하고 직전 상태로 롤백합니다.
- 실행 취소·다시 실행 후 기존 최근 작업 복구본 저장을 요청합니다.
- 단순히 다른 글자를 선택하거나 가이드 표시를 바꾼 동작은 편집 단계에 넣지 않습니다.

## 기존 기능과의 관계

실행 취소는 현재 브라우저 세션의 빠른 편집 복구 기능입니다. IndexedDB 기반 최근 작업 복구본은 브라우저를 닫거나 더 오래된 시점으로 돌아갈 때 사용하는 별도 안전장치로 유지됩니다.
