# PDF 선택 구간 지연 미리보기

## 목적

대용량 PDF에서 전체 출력면을 한꺼번에 캔버스로 만들지 않고도 현재 작업 위치의 실제 내용을 확인할 수 있게 한다. 최종 PDF 생성 경로와 전체 출력 품질은 변경하지 않는다.

## 활성 기준

다음 중 하나이면 선택 구간 미리보기를 사용한다.

- 출력면이 80개를 초과함
- 기존 대용량 최적화 모드가 활성화됨
- 기존 초대용량 목록 모드가 활성화됨

일반 문서는 기존 전체 미리보기를 그대로 사용한다.

## 표시 범위

- 대용량 문서: 현재 출력면 앞뒤 3개, 최대 7개
- 초대용량 문서: 현재 출력면 앞뒤 2개, 최대 5개
- 문서 시작과 끝에서는 같은 최대 개수를 유지하도록 범위를 당긴다.

상단 이동 메뉴에서 이전·다음 출력면과 출력면 번호 직접 입력을 지원한다. 현재 구간 끝에서 마우스 휠을 계속 내리거나 올리면 다음·이전 구간으로 교체한다.

## 출력 배치 일치

현재 편집기의 다음 함수를 그대로 사용한다.

- `bookletReorderPreview`
- `groupByNup`
- `getLayout`
- `buildOutputPage`
- `applyDocEdits`
- `PdfPrintMarks.addMarksToCanvas`

각 작업 미리보기에는 전체 문서 기준 출력면 번호를 전달하므로 페이지 번호·머리말·꼬리말·워터마크가 최종 출력과 같은 번호를 사용한다.

## 전역 위치 보호

지연 미리보기에는 전체 출력면 중 일부만 DOM에 존재하므로 기존 로컬 순번을 그대로 사용하는 기능은 위치가 어긋날 수 있다.

- 빈 페이지와 간지 삽입 영역은 지연 미리보기에서 숨기고 버튼을 비활성화한다.
- 해당 기능은 왼쪽 페이지 목록에서 사용하도록 안내한다.
- 기존 N-up 출력 주석은 숨기고 각 노드의 `data-output-index`를 기준으로 전역 출력면을 표시한다.
- 소책자 모드에서는 전역 출력면으로 용지 번호와 앞면·뒷면을 계산한다.
- 미리보기 DOM이 다시 만들어지면 MutationObserver가 보호 상태와 전역 주석을 다시 적용한다.

## 초대용량 원본 페이지 표시

300페이지 이상 가져오기 단계에서는 메모리 보호를 위해 페이지 번호 상자를 저장한다. 사용자가 해당 페이지를 선택하면 작업 미리보기 모듈이 다음 순서로 실제 내용을 준비한다.

1. `uploadedFiles[file_index]`에서 해당 원본 PDF를 찾는다.
2. 같은 표시 구간에 속한 동일 파일은 한 번만 연다.
3. 필요한 `page_index` 페이지만 PDF.js에서 읽는다.
4. 안전한 축소 렌더러로 실제 썸네일을 만든다.
5. 현재 출력면 캔버스에 배치한 뒤 임시 페이지와 PDF 문서를 해제한다.

한 페이지를 읽지 못해도 해당 위치에 오류 안내 페이지를 표시하고 다른 출력면 미리보기는 계속 만든다.

## 이용 방법

- 왼쪽 페이지 목록을 클릭하면 해당 페이지가 포함된 출력면을 중심으로 표시한다.
- `이전`, `다음`으로 한 출력면씩 이동한다.
- 출력면 번호를 입력하고 Enter를 누르면 바로 이동한다.
- 미리보기 구간의 위·아래 끝에서 휠을 계속 움직이면 인접 구간을 불러온다.
- 화면에는 일부 출력면만 보여도 최종 PDF 저장에는 전체 문서가 반영된다.
- 지연 미리보기에서 빈 페이지·간지 삽입은 왼쪽 페이지 목록에서 처리한다.

## 변경하지 않는 항목

- 최종 PDF 생성 시 사용하는 `buildAllPages`
- PDF 다운로드 버튼 처리
- 원본 페이지 배열과 파일 배열
- 페이지 순서·숨김·회전·N-up 설정
- Firebase 편집 저장 형식
