# 책표지 책등 글자 인쇄 적합성

기준일: 2026-08-06

## 목적

책등은 폭이 좁고 글자가 세로 방향으로 회전해 출력되므로 화면에서는 보이더라도 실제 PDF에서 표지 영역으로 번지거나 긴 문구가 심하게 눌릴 수 있다. 현재 상·중·하단 책등 글자 레이어를 각각 검사하고 인쇄 전 자동 점검과 최종 PDF 확인에 연결한다.

## 실제 렌더링 기준

- 책등 폭이 2.2mm 미만이면 현재 렌더러는 책등 글자를 출력하지 않는다.
- 각 글자의 실제 크기는 글자 크기와 레이어 확대율을 곱해 계산한다.
- 회전된 글자의 높이가 책등 폭에서 차지하는 비율을 계산한다.
- 문구 길이는 현재 렌더러의 최대 너비인 완성 세로의 28%를 기준으로 압축 비율을 계산한다.
- 각 글자의 세로 위치와 실제 출력 길이를 이용해 책등 레이어끼리 겹치는지 확인한다.

## 판정

- 책등 2.2mm 미만에 문구가 있으면 `출력 안 됨` 오류
- 글자 높이가 책등 폭의 90%를 넘으면 `폭 초과` 오류
- 긴 문구가 원래 너비의 65% 미만으로 줄면 `심한 가로 압축` 오류
- 글자 높이가 책등 폭의 72%를 넘으면 `여백 부족` 주의
- 긴 문구가 원래 너비의 85% 미만으로 줄면 `가로 압축` 주의
- 실제 크기가 6pt 미만이면 `작은 글자` 주의
- 두 책등 글자의 출력 영역이 2mm 넘게 겹치면 레이어 겹침 주의

## 자동 맞춤

- 문제가 있는 책등 레이어에 한해서 안전한 기본 글자 크기를 계산한다.
- 글자 높이가 책등 폭의 약 72% 안에 들어오도록 제한한다.
- 긴 문구가 원래 너비의 최소 85% 이상을 유지하도록 크기를 제한한다.
- `문제 있는 글자 크기 맞추기` 버튼을 누르면 해당 책등 레이어만 수정한다.
- 앞표지와 뒤표지 글자, 위치, 색상은 변경하지 않는다.

## 출력 연결

- 책등 글자 오류는 인쇄 전 자동 점검의 오류로 추가돼 300DPI PDF 생성을 막는다.
- 주의나 자동 크기 조정 권장은 확인 후 출력할 수 있다.
- 오류를 수정하거나 자동 맞춤을 적용하면 미리보기와 글자 편집 목록을 즉시 갱신한다.
