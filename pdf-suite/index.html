01 · PAGE & DOCUMENT

페이지·문서 구성

문서를 합치고, 나누고, 순서를 정리합니다.
바로 사용🔗PDF 합치기여러 PDF를 지정한 파일 순서대로 하나로 결합합니다. 바로 사용✂️페이지 추출·나누기1-3,5처럼 원하는 페이지만 새 PDF로 저장합니다. 바로 사용🗂️시각적 페이지 정리썸네일을 보며 순서 이동·삭제·복제 후 새 PDF로 저장합니다. 바로 사용🧹빈 페이지 자동 제거스캔 문서 등에 섞인 빈 페이지를 감지해 제거합니다. 바로 사용➕빈 페이지 삽입표지·간지·구분용 빈 페이지를 필요한 위치에 추가합니다. 바로 사용↔️펼침면 좌우 분리한 페이지에 붙어 있는 좌·우 면을 개별 페이지로 나눕니다. 로컬🔄전체 페이지 회전모든 페이지를 90°·180°·270° 회전해 새 PDF를 만듭니다. 로컬🔃페이지 순서 역순마지막 페이지부터 첫 페이지까지 순서를 한 번에 뒤집습니다.
02 · CONVERT & EXTRACT

변환·추출

PDF와 이미지 사이의 실무 변환을 처리합니다.
바로 사용🖼️이미지 → PDFJPG·PNG·GIF·BMP·TIFF·WEBP 이미지를 PDF 페이지로 변환합니다. 바로 사용📸PDF 이미지 변환PDF 페이지를 이미지 작업 흐름으로 변환·활용합니다. 바로 사용📑선택 페이지 → PDF필요한 페이지만 골라 독립된 PDF 문서로 분리합니다.
확장 예정🔤OCR 문자 인식스캔 이미지의 글자를 인식해 검색 가능한 PDF로 만드는 기능입니다.
확장 예정📝텍스트·문서 추출PDF 본문을 구조화된 텍스트나 편집 가능한 문서로 내보내는 기능입니다.
확장 예정📎첨부파일 추출PDF 내부에 포함된 첨부파일과 임베디드 자원을 추출합니다.
03 · EDIT & LAYOUT

편집·레이아웃

출력용 페이지 구성과 반복 편집을 처리합니다.
바로 사용▦N-up 다면 배치한 장에 여러 페이지를 2-up·4-up 등으로 배치합니다. 바로 사용📖소책자·중철 배치소책자 인쇄 순서와 물리 시트 구성을 자동 배치합니다. 바로 사용#️⃣페이지 번호쪽번호를 자동 배치하고 미리보기와 출력 결과를 맞춥니다. 바로 사용↕️머리말·꼬리말반복되는 제목·문구를 페이지 상단이나 하단에 배치합니다. 바로 사용💧워터마크문서 위에 반복 워터마크를 적용해 출력용 PDF를 만듭니다. 바로 사용🔖간지·구분 페이지텍스트·이미지 기반 간지를 만들어 문서 중간에 삽입합니다. 바로 사용📐여백·크롭·배경페이지 여백 제거·크롭·배경색 등 출력 전 페이지 외곽을 정리합니다.
확장 예정✏️주석·형광펜·도형검토 주석과 자유 그리기, 도형, 스탬프를 PDF에 직접 추가합니다.
04 · SECURITY & PRIVACY

보안·개인정보

암호와 문서 정보 노출을 관리합니다.
바로 사용🔐AES-256 암호 설정PDF에 강력한 AES-256 비밀번호 보호를 적용합니다. 바로 사용🔓암호 해제올바른 비밀번호로 열린 PDF를 암호 없는 새 파일로 저장합니다. 로컬ℹ️메타데이터 확인제목·작성자·주제·프로그램 정보를 브라우저에서 확인합니다. 로컬🧼메타데이터 정리제목·작성자·주제·키워드 등 일반 문서 메타데이터를 비웁니다. 로컬📋폼 평면화입력 가능한 PDF 폼 필드를 현재 표시 상태로 고정합니다.
확장 예정⬛영구 마스킹·Redaction민감 정보를 실제 콘텐츠에서 제거하는 안전한 영구 마스킹 기능입니다.
확장 예정✍️전자서명서명 이미지 및 인증서 기반 디지털 서명 워크플로를 추가할 예정입니다.
05 · PRINT & PUBLISHING

인쇄·출판

인쇄소 실무에 필요한 검사와 출력 배치를 묶었습니다.
바로 사용✅PDF 프리플라이트페이지 크기·이미지·폰트·인쇄 위험 요소를 사전 점검합니다. 바로 사용🔍인쇄물 사전 검토재단선·안전영역·책등·접지선과 실제 출력 규격을 검토합니다. 바로 사용✚재단·인쇄 마크재단표시와 인쇄용 보조 마크를 출력 PDF에 구성합니다. 바로 사용🧩대형 분할 출력큰 페이지를 여러 장으로 타일 분할해 출력할 수 있게 만듭니다. 바로 사용🛠️안전 자동 수정검사 결과 중 안전하게 자동 교정 가능한 항목을 별도 파일로 수정합니다. 바로 사용📚책자 출력 배치소책자·중철용 시트 순서와 반복 배치를 구성합니다.
06 · SCAN & OCR

스캔·OCR

스캔 문서 정리는 일부 제공되고 OCR 엔진은 확장 예정입니다.
바로 사용🧹스캔 빈 페이지 정리스캔 과정에서 들어간 빈 페이지를 자동으로 감지해 제거합니다. 바로 사용🗜️스캔 PDF 압축해상도·품질 프리셋으로 스캔 PDF 용량을 줄입니다.
확장 예정🔤검색 가능한 PDFOCR 텍스트 레이어를 추가해 검색·복사가 가능한 PDF를 만듭니다.
확장 예정📏기울기 자동 보정비스듬하게 스캔된 페이지의 각도를 자동 감지해 바로잡습니다.
확장 예정✨스캔 노이즈·배경 정리종이 배경 얼룩과 노이즈를 줄이는 스캔 후처리 기능입니다.

최적화·호환성

확장 예정🏛️PDF/A 장기보존 변환보관 표준에 맞는 PDF/A 문서 생성과 준수 검증 기능입니다.
확장 예정🌐웹 빠른보기 최적화대용량 PDF를 순차 로딩하기 좋은 구조로 선형화합니다.
확장 예정🩹손상 PDF 복구열리지 않거나 참조 구조가 손상된 PDF의 복구 가능성을 검사합니다.

검사·분석

문서 구조와 인쇄 적합성을 확인합니다.
바로 사용🩺문서 구조·인쇄 진단페이지·이미지·폰트·인쇄 조건을 종합 점검하고 위험도를 표시합니다. 바로 사용🟢출력 준비 상태현재 편집·배치 상태가 출력 가능한지 최종 단계에서 점검합니다. 로컬🔎문서 메타데이터 분석문서에 남아 있는 제목·작성자·작성 프로그램 등의 정보를 확인합니다.
