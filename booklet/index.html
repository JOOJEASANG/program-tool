📋
인쇄면 순서
PDF를 업로드하면 인쇄면별 페이지 배치 순서표가 표시됩니다.
시트 인쇄면 왼쪽 (자리) 오른쪽 (자리)
1
PDF 인쇄 설정
프린터 인쇄 대화상자에서 양면 인쇄를 선택하고,
뒤집는 방향은 "긴 변(Long edge) 기준 뒤집기"를 선택합니다.
페이지 크기 조정 없이 실제 크기로 인쇄하세요.
2
인쇄 후 정렬
인쇄된 종이를 순서가 흐트러지지 않도록 주의하며 꺼냅니다.
앞면이 위를 향하도록 가지런히 정렬합니다.
3
접기 (폴딩)
가운데를 기준으로 반을 접습니다. 접힌 크기가 소책자 완성 크기입니다.
예) A4 출력 → 완성 크기 A5 (148 × 210 mm)
예) A3 출력 → 완성 크기 A4 (210 × 297 mm)
4
제본 (중철)
접힌 선 중간에 스테이플러로 2~3군데 고정합니다.
스테이플러 심이 닿지 않는 경우 중철 전용 스테이플러를 이용하세요.
💡
빈 페이지 안내
소책자는 전체 페이지 수가 4의 배수여야 합니다. 맞지 않을 경우 자동으로 빈 페이지가 추가됩니다.
