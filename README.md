# Program Studio

Program Studio는 인쇄·출력 실무를 위한 웹 도구 모음입니다.

현재 운영 프로그램은 다음과 같습니다.

- 디자인 검토/제작: 인쇄물 검토와 AI 표지 제작
- 스마트 인쇄배치: 실제 PDF 크기·수량 기반 자동배치
- PDF배치: N-up·소책자·간지·여백 설정
- PDF편집: 페이지 이동·자르기·회전·정밀 편집
- PDF 도구 모음: 검사·합치기·나누기·압축·변환

> 세부 운영 구조와 배포 정책은 `PROGRAM_STRUCTURE.md`, 각 프로그램 매뉴얼, 저장소의 기존 문서를 기준으로 합니다.

## 디자인 검토/제작 변경사항

`/print-checker/`는 기존 인쇄물 검토 기능을 유지하면서 같은 화면에서 AI 표지 제작을 선택할 수 있도록 확장되었습니다. AI 제작은 표지 전용이며, 뒤표지 + 책등 + 앞표지 전체 펼침 배경을 `gpt-image-2`로 생성하고 정확한 한글 제목·날짜·회사명·책등 글자는 편집 가능한 레이어로 처리합니다.

서버 설정 예시는 `backend/.env.example`을 참고합니다.
