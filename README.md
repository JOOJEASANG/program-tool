# Program Studio

Program Studio는 인쇄·출력 실무를 위한 웹 도구 모음입니다.

## 주요 프로그램

- **디자인 검토/제작** — PDF·이미지 인쇄물을 재단 규격, 도련, 안전 영역, 책등·접지 기준으로 검토하고 같은 화면에서 AI 표지 제작을 사용할 수 있습니다. AI 표지는 뒤표지 + 책등 + 앞표지 전체 펼침 구조로 만들며, 배경은 GPT Image 2가 생성하고 정확한 한글 제목·날짜·회사명·책등 글자는 편집 가능한 레이어로 처리합니다.
- **스마트 인쇄배치** — PDF의 실제 크기와 수량을 읽어 용지에 자동 배치하고 양면 위치를 맞춥니다.
- **PDF배치** — 여러 PDF의 페이지 정리, N-up, 소책자, 간지, 여백 설정을 제공합니다.
- **PDF편집** — 페이지 이동, 크기 조절, 자르기, 회전 등 정밀 편집을 제공합니다.
- **PDF 도구 모음** — 인쇄 전 검사, 합치기·나누기·압축·변환 등 PDF 작업을 제공합니다.

## 디자인 검토/제작

### 디자인 검토

- 완성 규격 기본값: A4 210 × 297 mm
- 사용자가 입력한 완성 가로·세로, 책등, 도련 값을 기억해 다음 작업과 AI 표지 제작에서 재사용
- 표지, 리플렛, 전단지·포스터, 초대장·안내장, 소책자 검토
- PDF·PNG·JPEG·WEBP 지원
- 재단선, 안전 영역, 도련, 책등, 날개, 접지선과 실제 파일 비교

### AI 표지 제작

- AI 제작은 **표지 전용**
- 전체 펼침: 뒤표지 + 책등 + 앞표지 + 외곽 도련
- 서버 이미지 모델: `gpt-image-2`
- AI는 배경 아트워크만 생성하고 실제 한글 문구는 브라우저 편집 레이어로 처리
- 책등 제목, 날짜·연도, 하단 회사명 지원
- 책등 글자 방향: 세로글씨, 90도 아래→위, 90도 위→아래
- 책등 폭별 안전 정책
  - 4mm 미만: 책등 문구 제외
  - 4~7.9mm: 제목
  - 8~11.9mm: 제목 + 날짜
  - 12mm 이상: 제목 + 날짜 + 회사명
- 디자인 프리셋 선택 후 프롬프트 직접 수정 가능
- 생성 결과를 같은 미리보기 영역에서 확인
- 300dpi 기준 전체 펼침 PNG 저장

## AI 서버 환경변수

```env
OPENAI_API_KEY=
OPENAI_AI_DESIGN_MODEL=gpt-5.6-sol
OPENAI_AI_IMAGE_MODEL=gpt-image-2
OPENAI_AI_IMAGE_QUALITY=high
```

`OPENAI_API_KEY`는 서버 환경에만 저장하며 브라우저 코드에 포함하지 않습니다.
